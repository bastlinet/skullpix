# Skullpix implementation plan

**Goal:** Implement the user-specified headless pixel-art compiler in one small package.

**Architecture:** Typed schema and safe parser feed independent Pillow operations;
renderer, diagnostics and CLI have separate responsibilities.

**Tech stack:** Python 3.12+, Pillow, Pydantic 2, Typer, PyYAML, pytest.

**Spec:** ../specs/2026-09-29-skullpix-design.md

## Global constraints

- Integer coordinates, no anti-aliasing, no hidden state, strict extra-field rejection.
- Canonical YAML and equivalent JSON; ordered layers and operations.
- No GUI, image import, animation, sheets, AI APIs or plugin systems.
- MIT; independently implemented using general raster algorithms.

## Review focus

- Reject implicit numeric coercions and duplicate keys with actionable paths.
- Diagnose clipping created by outlines and transforms, including rectangular canvases.
- Match alpha exactly for fills/replacement; count composited colors for constraints.
- Emit JSON diagnostics rather than tracebacks on malformed or unreadable inputs.
- Verify PNG bytes independently of metadata, hash seed and compression libraries.

## Tasks (each uses failing tests, implementation, then the full pytest suite)

- [x] 1. Package, strict schema, parser, palette and diagnostic types.
  Files: pyproject.toml, skullpix/{schema,parsing,palette,diagnostics}.py,
  tests/test_parsing.py. API: load_asset(path) -> Asset; AssetError.result.
  Cases: YAML/JSON equivalence, duplicate keys, integer/size constraints,
  unsupported operations, alias rejection, malformed colors and unknown fields.
- [x] 2. Canvas, pixel/pixels, Bresenham line, rectangles, ellipses, polygons and layers.
  Files: skullpix/operations/draw.py, skullpix/renderer.py, tests/test_render.py.
  API: render_asset(asset) -> Pillow Image. Assert small literal pixel matrices,
  box extents, reversed line endpoints, visibility, order and RGBA composition.
- [x] 3. Exact flood fill/replacement, outlines and transforms.
  Files: skullpix/operations/{fill,outline,transform}.py, tests/test_operations.py.
  Test 4-connected fill, outline snapshot 4/8 neighbors, no occupied overwrite,
  all rotations, mirrors, combined transform order and rectangular anchoring.
- [x] 4. Semantic validation, lint and statistics.
  Files: skullpix/validation/{checks,lint}.py, skullpix/inspection.py,
  tests/test_validation.py. API: validate_asset(asset), lint_asset(asset).
  Test color suggestions, duplicates, bounds including hidden layers and derived
  pixels, strict behavior, singleton/components and composited max_colors.
- [x] 5. Canonical PNG and CLI.
  Files: skullpix/{png,cli,__main__}.py, tests/test_{png,cli}.py.
  Test round-trip PNG with Pillow, metadata exclusion, byte identity; validate,
  lint, inspect JSON and render output/strict/exits, unreadable input/output.
- [ ] 6. Examples, goldens, documentation and packaging verification.
  Files: examples/{skull,frog,sword}.yaml, tests/golden_sha256.json,
  tests/test_examples.py, README.md, docs/format.md, LICENSE, uv.lock.
  Run full pytest, build wheel/sdist, clean install and acceptance commands;
  fresh review, fix material findings with regression tests, final summary.

## Progress and decisions

- Initial: user supplied a complete implementation brief; proceed within that
  authorization, without additional design approval gates. New standalone
  repository provides isolation. Work remains local.
- Phase 1: 27 tests passed; phase 2: 46; phase 3: 68; phase 4: 87;
  phase 5: 119. Every phase ran the whole suite after its failing tests.
- Ruling: use stored DEFLATE blocks in a small canonical PNG encoder to ensure
  byte identity across compression library versions; tradeoff is larger files.
- Ruling: quarter turns swap layer dimensions and anchor at the top-left before
  translation and clipping; avoids fractional centers on rectangular canvases.
- CLI --version regression: Typer required a command before invoking the group
  callback; invoke_without_command fixes it, confirmed by the CLI test.
- Examples rendered and visually inspected; goldens recorded. 123 tests pass,
  including separate interpreter processes with different hash seeds.
